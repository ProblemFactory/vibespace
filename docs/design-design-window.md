This is the design the Design window was built from, kept in the repository (the Chinese twin: docs/design-design-window.zh.md). Each section names the lane that owns it: **L1** lane design-core (the model, the hub, the routes, the CLI), **L2** lane design-window (the window, the canvas, the chip, the published page's runtime), **L3** lane design-docs-removal (the manual and the craft rules, the Claude CLI kit removed, the migration, the changelog), **L4** lane design-chrome (the browser gate + the verify round). §3.7–§3.9 record what each lane built where the contract left a shape open.

**Owner's words (2026-10-02 04:30 PDT):** "要不别依赖claude cli了，我们直接自己复刻一个更好的版本。" — supersedes the 04:05 "legacy donor pin (K4)" ruling. Earlier, still binding: no account-bound vendor path (multi-account system); 不要过度设计; daily-use first.

**Study:** one workflow (3 readers: skill text / runtime + helper / VibeSpace side + usage → 3 directions A viewer-first, B native window, C editor parity → 2 judges). Both judges picked **B** (34 and 35 of 40; A 32/29; C 28/22). (The study's texts are kept outside the repository.)

## 0. Thesis (all lanes)
The canvas is a **VibeSpace window type `design`** that renders plain-HTML artboards living in the conversation's cwd (`designs/<slug>/`). No template language, no vendor runtime, no vendor file, no account. The agent writes artboards with the editor tool it already has (claude / codex / opencode alike); `design.json` places them; the window repaints one frame in place when a file changes; a click on an element becomes a quoted comment the agent receives as the user's own message; Publish bundles the same files into one self-contained page on `/p/<id>` under the existing CSP sandbox (same URL on republish). The Claude CLI kit (`src/server/design-kit.js` + the unmerged donor ladder of lane design-kit-287) is deleted; `data/design-kit/` (vendor text) removed by a migration.

## 1. What the old kit was (measured on CLI 2.1.274's extraction; the owner's 3 canvases) — L3 removes it
- SKILL.md 56 KB (the process + a vendor template grammar: `<x-dc>`, `{{dotted holes}}`, `sc-for`/`sc-if`, `dc-import`, `DCLogic` components with `data-props` tweak chips) · seed-canvas.mjs 40 KB (title/filename gates, `<` escaping, `--extract`, `--check`) · payload.template.html 2.4 MB (React 19 + Base UI + Tailwind v4, pan/zoom, pages, sticky notes, export PNG/JPEG/PDF/zip hand-written, comments, undo, direct manipulation via `data-dc-tpl` source maps; Save = `window.claude.self.publish` — absent on VibeSpace, so /p pages were view + export only).
- Usage: 3 canvases (08-21…08-24, all public, ~2.4 MB each) vs 16 plain page publishes (08-25 → 10-01). Nobody edited a canvas by hand; every change went through the agent.
- It broke on CLI changes three times in six weeks (2.366.0, 2.1.257 zstd frames, 2.1.287 removal) and the donor rung executes an extracted third-party helper server-side (verify r1: two MEDIUMs; `execFile` without a sanitized env).
- The 2.1.287 official path = claude.ai Design artifacts, account-bound ⇒ rejected.

## 2. Why B (and not A / C) (all lanes)
- **A (viewer-first replica)** re-implements the vendor's artboard grammar as OUR spec for ever; codex/opencode agents would learn a dialect instead of writing HTML; the human still sees nothing until publish. Its only unique value is rendering the 3 August canvases (~700 lines of a vendor-language renderer for 3 pages nobody opened since 08-24).
- **C (editor parity)** is honest that it is overdesign: +9–11k lines for hand editing the record says never happens; retype-in-place would refuse the hole-bound text of 2 of the 3 real canvases.
- **B** needs no grammar, no runtime of theirs, nothing extracted; gives what the kit never gave: watching the draft fill in while the agent works, pointing at an element to say "this one, bigger".

## 3. THE CONTRACT (L1 and L2 build against this in parallel — do not change it without the integrator)
### 3.1 Files in the conversation's cwd (L1 reads them, L2 draws them, L3 teaches them)
```
designs/<slug>/
  design.json      optional manifest (absent ⇒ artboards in a row, by name, Main first)
  Main.html        the entry artboard: a complete HTML document (inline <style>/<script> allowed)
  <Name>.html …    names ^[A-Za-z0-9_][A-Za-z0-9 _.-]{0,80}\.html$, unique case-insensitively, ≤ 2 MiB
  logo.png …       images referenced RELATIVELY (src="logo.png" / url(logo.png)); png/jpg/jpeg/gif/webp/svg ≤ 2 MiB each; inlined as data: at read + publish
```
`design.json` (closed keys — the validator refuses by name what the loader would drop):
```json
{ "title": "Spring menu",
  "pages": [{"id":"p1","name":"Flows"}],
  "artboards": [{"file":"Main.html","x":0,"y":0,"w":1280,"h":800,"title":"Home","page":"p1","print":"fixed"}],
  "notes": [{"id":"n1","x":0,"y":-160,"w":320,"text":"Direction A: calm","color":"blue","page":"p1"}],
  "launch": {"view":"canvas","page":"p1"} }
```
Bounds: `w`/`h` 120–8000 (frame the iframe, never scale); `print` fixed|flow (print CSS only); ≤ 40 artboards per read, ≤ 40 pages, ≤ 200 notes, note text ≤ 5000, 8 named note colours (gray red orange green teal blue purple pink → theme vars); `launch` = `{view:"canvas", page?}` | `{view:"focused", file}`. Unknown top-level or row keys ⇒ refused by name. Rows are laid out with ≥ 80 px gaps (row) / 120 px (rows) when absent; overlaps are WARNED, never moved.
### 3.2 PURE `src/design-model.js` (CJS, imports nothing; bundled into the client, required by the hub) — L1
`validateManifest(json) → {ok, manifest} | {ok:false, refusals:[{code, where, why}]}` · `layoutOf(manifest, artboardNames)` (row placement for missing rows) · `artboardVerdict(name, html, {assets}) → {ok} | {ok:false, code, why}` (name grammar, size, `<html>`+`<body>` present, no `<base>`, every relative ref resolves) · `inlineAssets(html, readAsset)` (the ONE bundler the window AND publish use) · `elementPath(nodeFacts)` + `pickQuote({file, path, tag, text})` = the comment's quote line, text ≤ 120 chars · `bundleCanvas({manifest, files, runtimeJs}) → html` with `<script type="application/json" id="vibespace-design-doc">` (`<` escaped) · `readBundle(html)` the inverse · `commentText(quote, text)` = `[Design comment] Main.html › header > nav > a.cta ("Get started"): <text>` — the WHOLE line goes through `src/peer-text.js` `toAgentText` (census row: an artboard written by another agent of a shared Task Group could forge a frame) · `sizeVerdict(bytes)` (warn > 8 MB, refuse ≥ 25 MB by name).
### 3.3 ORCH `src/server/design-engine.js` + `src/routes/design.js` + ws — L1
- Registry `data/designs.json` rows `{id, sessionId, conversationId, host, dir, title, createdAt, openedAt}` — one per (host, dir), `writeJsonAtomic`, `designs-updated` broadcast on every write.

A change ⇒ the existing `file-changed {host, path, mtime, by:'design'}` broadcast per file.

### 3.7 L1 as built (lane design-core, 2026-10-02) — what the contract did not spell, now fixed (additive; no key / route / openSpec of §3.1–§3.6 changed)
- **Model.** `inlineAssets(html, readAsset)` → `{html, inlined:[names], missing:[names]}`; `readAsset(name)` returns the file as BASE64 (or null). Bounds the contract left open: coordinates ±100000; an artboard row's `x`/`y` both or neither (neither = placed in the row; `w`/`h` default 1280×800); note `w` 40–4000, a note's `id`/`x`/`y`/`w`/`text` required, `color` default `gray`; page / note ids `^[A-Za-z0-9_-]{1,40}$`; a page without `name` is named by its id. `layoutOf` frames carry `{file, x, y, w, h, title, page, print, placed:'manifest'|'auto', missing, dup}`. Relative refs = `src=` on a tag + `url()` in a style attribute / `<style>` block (never inside a script / comment / textarea); a root path, a subfolder, a non-image is `bad_ref`. State block = `{v:1, title, manifest, files:{<name>: inlined html}}`. Also exported: `commentVerdict(text)` (empty / >4000 refused), `readCapsVerdict`, `assetRefsOf`, `PLACEHOLDER_RUNTIME` (rides a publish until public/design-viewer.js exists).
- **`GET /api/design?host&dir`** → `{ok, host, dir, design, title, manifest, refusals:[{code, where, why}], warnings, frames:[{…layout, bytes, mtime, verdict:{ok}|{ok:false, code, why}, html (only when ok, images inlined)}], pages, notes, launch, totalBytes, overBudget, readAt, mtimes:{name: ms}}`; failures `{error, code}` (`not_registered` 404, `too_big` 413, `not_found` 404, `host_unreachable` 502, `bad_dir` 400). A refused design.json comes back as `refusals` with the frames laid out WITHOUT it (never a blank window).
- **`GET /api/design`** ALSO carries `artboards: [{file, html, ok:true} | {file, ok:false, code, why}]` beside `frames` (the window's read shape — same verdicts; added for L2's normaliser, step 4).
- **`GET /api/designs?sessionId&conversationId`** — either matches (a resume mints a new session id; none given = every row); rows carry `page: {id, path, public, updatedAt} | null` (the published page of that folder, srcKey `<host|local>:<dir>`).
- **`POST /api/design/publish`** answers the pages publish shape `{ok, page: {id, name, url, path, public, replaced, …}, size, frames}`; failures `{error, code}` (`not_publishable` 409 names the refused manifest / the first refused artboard, `too_big` 413).
- **Bounds** the contract did not name: the registry keeps 1000 rows (least recently opened leave), one read ≤ 200 images, a watch ≤ 16 folders per socket / 32 in all.
- **`POST /api/design/comment`** body adds `host, dir` (optional): when no live chat process takes the comment, they name the design whose conversation the stash entry waits for. Answer `{ok, delivered:'sent'|'stashed', msgId?, conversationId?, text}` (`text` = the belted line). Refusals `empty` / `too_long` / `no_conversation` 409 / `input_rejected` / `too_large` / `send_failed`.
- **The push that opens the window** = `design-open {sessionId, design, openSpec:{action:'openDesign', host, dir, sessionId}}` to the registering session's clients (`broadcastToSession`). **`designs-updated {design, created?}`** to every client on each registry write (the chip re-fetches its session's list).
- **ws ack**: `design-watch` / `design-unwatch {host, dir, reqId?}` are answered `design-watch-ack {op:'watch'|'unwatch', host, dir, ok, watchers?, polled?, code?, error?}` — NO sessionId. `polled:false` = a remote folder (refcounted, never polled: the CLI's `sync` repaints it).
- **Agent routes added**: `GET /api/agent/designs` (the CLI's `list`: rows with belted titles + `page`); `POST /api/agent/design/publish` takes `page` (an existing page THIS conversation published — the cut table's "publish --page" graft) → `page_forbidden` 403 otherwise. `check` answers the AGENT's view (verdicts + layout + page names + note texts, every string through the belt, never the HTML) + `size`.
- **Stash**: a waiting comment is `{source:'design-comment', kind:'peer', fromName:'Design comment'}`; src/stash-summary.js has the kind `design-comment` ("a design comment" — zh/ja added to src/lib/i18n-zh.js / i18n-ja.js by L1: 2 + 4 card-word keys, next to "a window request").
